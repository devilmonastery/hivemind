# Hivemind: a simple collaborative knowledge base for Discord guilds

## Overview
This is an app called "hivemind", to allow members of Discord guilds to collaboratively create and edit knowledge base articles on various topics.

## Development Environment

### Database Access
The development environment runs in Kubernetes via Tilt (not docker-compose). The PostgreSQL database is deployed as a Kubernetes pod.

**Finding the namespace and pods:**
```bash
# The namespace is based on your username: hivemind-<username>
kubectl get pods -n hivemind-mrothwell
# Should show postgres-0, hivemind-bot-*, hivemind-server-*, hivemind-web-*
```

**To access the database:**
```bash
# Connect to postgres
kubectl exec -it -n hivemind-mrothwell postgres-0 -- psql -U postgres -d hivemind

# Run a query
kubectl exec -it -n hivemind-mrothwell postgres-0 -- psql -U postgres -d hivemind -c "SELECT * FROM discord_guilds;"

# Describe a table
kubectl exec -it -n hivemind-mrothwell postgres-0 -- psql -U postgres -d hivemind -c "\d discord_guilds"
```

Do NOT try to access via `docker exec hivemind-postgres` - that container doesn't exist in the Tilt/k8s setup.

### PostgreSQL Interval Types
When passing Go `time.Duration` to PostgreSQL interval parameters, convert to seconds first:
```go
// BAD - passes nanoseconds which PostgreSQL can't handle
query := `... NOW() + $1::interval`
db.Query(query, duration) // duration = 86400000000000 (causes "out of range" error)

// GOOD - convert to seconds and format as string
intervalSeconds := int(duration.Seconds())
query := `... NOW() + ($1 || ' seconds')::interval`
db.Query(query, intervalSeconds) // intervalSeconds = 86400
```
